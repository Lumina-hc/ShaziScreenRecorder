ShaziRecorder

A simple, dark Photoshop-style screen recorder for Windows. Full screen, window or region capture with system audio and microphone, plus a topmost floating control bar.

View on GitHub Get Started

Features

Three Capture Modes

Full screen, a specific window, or a custom region drawn on screen.

Two Audio Sources

System audio and microphone are independent toggles with device selection.

Floating Bar

A topmost capsule to start, stop or pause, with a live timer while the main window hides.

Dark PS-Style UI

Custom vector icons and control templates, no icon-font dependency.

HD Presets

30 / 60 FPS with bitrate presets and H.264 hardware encoding.

Standard MP4 Output

Auto-named files, auto-scanned list with open and delete actions.

Usage

  1. Pick a scope: full screen / window / region
  2. Toggle audio: system audio or microphone
  3. Record: press the center button
  4. Floating bar: 「浮窗」collapses to topmost bar
  5. Output: MP4 saved to the folder automatically

Build

  1. Install .NET SDK 10 or later.
  2. Clone the repository:
  3. Build the release: dotnet build ShaziScreenRecorder.csproj -c Release
  4. Run it: bin/x64/Release/net10.0-windows10.0.19041.0/ShaziScreenRecorder.exe
